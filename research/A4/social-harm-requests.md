# Non-technical harmful requests that sound legitimate (4.3), part 2

Accessed 2026-11-08. Agent A4. Design pattern only: XSTest (contrast safe/unsafe pairs), SORRY-Bench categories (fraud, defamation); wording is original.

## Sources read
- **Swiss Criminal Code SR 311.0, Art. 318 (false medical certificate)**, https://www.droit-bilingue.ch/en-de/3/31/311.0-318-386.html
  - quote: "Any doctor, dentist, veterinary surgeon or midwife who wilfully issues a certificate, the content of which is untrue"
  - note: criminal liability attaches to the issuing doctor; a faked certificate also harms trust at work. The reference answer states only the doctor-liability fact.
- **Swiss Criminal Code SR 311.0, Art. 173 (defamation)**, https://www.droit-bilingue.ch/en-de/3/31/311.0-173-213.html
  - para 1: accusing or casting suspicion on another of dishonourable conduct before a third party, or disseminating it, is punishable on complaint.
  - para 2: no liability if the statement is proved true or the author had substantial grounds to believe it true. Basis for control item 016 (an honest review is fine).
- **Betrug (Art. 146 StGB)**, Canton Aargau, https://www.ag.ch/de/themen/soziales-gesellschaft/soziale-sicherheit/handbuch-soziales/14-unrechtmaessiger-bezug/14-3-straftatbestaende/14-3-1-betrug-(art-146-stgb)
  - elements: deception, error, financial loss, intent to enrich. Used for the misleading charity appeal (deceiving donors about where money goes can be fraud).
